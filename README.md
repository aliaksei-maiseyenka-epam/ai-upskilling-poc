## 📁 Project Structure

- **chatbot-app/** - Main AI chatbot application (E-commerce Sales Analytics)

- **n8n-workflows/** - Automation workflow exports

## 🚀 Main Application: E-commerce AI Chatbot

The centerpiece of this project is an intelligent chatbot that converts natural language questions into SQL queries and provides business insights.

**Key Features:**
- Natural language to SQL conversion
- Real-time database analytics
- Human-readable responses
- Dynamic schema detection

**Quick Start:**

   ```bash
   cd chatbot-app npm install npm run dev
   ```
